# 任务执行检查清单

## 使用说明
每个任务执行前、中、后都要按照此清单进行检查。

---

## 📋 任务开始前检查（必须）

- [ ] **风险评估**：评估任务风险等级
  - 高风险：涉及删除、覆盖、重置等操作
  - 中风险：涉及配置修改、批量操作等
  - 低风险：只读操作、查看信息等

- [ ] **Git状态检查**：执行 `git status`
  - 工作目录是否干净？
  - 是否有未提交的更改？
  - 是否有冲突需要解决？

- [ ] **自动快照创建**：
  - 运行 `. .trae\auto_protect.ps1 -Action protect -TaskId "任务描述"`
  - 记录快照SHA到下方

- [ ] **当前版本记录**：
  - 当前HEAD SHA: ___________
  - 当前分支: master
  - 备份分支: backup-before-work

- [ ] **任务目标确认**：
  - 明确要解决的问题或实现的功能
  - 确认修改范围
  - 准备回滚方案

## 🚨 异常情况处理

### 如果出现问题
1. **立即停止**：不再执行下一步操作
2. **检查状态**：`git status`
3. **查看历史**：`git reflog`
4. **准备恢复**：确定要恢复到的版本
5. **执行恢复**：`. .trae\auto_protect.ps1 -Action restore -RecoveryPoint "备份分支"`
6. **验证恢复**：检查文件是否恢复
7. **记录问题**：在操作日志中记录

### 紧急联系
- 备份分支：backup-before-work
- 最新快照：backup/snapshot-最新时间戳

## 🔒 重要命令速查

```powershell
# 创建任务快照
. .trae\auto_protect.ps1 -Action protect -TaskId "任务描述"

# 查看所有备份
. .trae\auto_protect.ps1 -Action backups

# 恢复版本
. .trae\auto_protect.ps1 -Action restore -RecoveryPoint "分支名或SHA"

# 检查命令风险
. .trae\auto_protect.ps1 -Action check -TaskId "git reset --hard"

# 查看Git状态
git status

# 查看操作历史
git reflog
```
